  → Edge Function send-notification → FCM topic requests_{governorate}

Technician: technician_dashboard.dart
  → Firestore requests.where(status==pending, governorate==techGov).snapshots()
  → submit offer → Firestore offers.add({requestId, technicianId: phone})
  → Customer: offers.where(requestId==...).snapshots() → accept
  → Firestore requests.update(status=accepted, technicianId, acceptedPrice)
  → Supabase notifications.insert() + FCM push both sides

Supabase PostgreSQL — 7 Tables

All: id UUID PK gen_random_uuid() · created_at TIMESTAMPTZ · RLS enabled. Models already in lib/core/models/.

🔔 notifications — in-app inbox + push log
user_id text (Firebase UID/phone)
user_type text  user|technician
title, body text
type text  request_update|payment|chat|system|promo|verification
data jsonb default '{}'
is_read bool
idx: (user_id, is_read, created_at desc)

Dart: app_notification.dart:1 + notification_repository.dart:1 matches 1:1. Realtime: stream(primaryKey:['id']).eq('user_id', uid)

⭐ reviews — technician ratings
request_id text, reviewer_id text (UID)
technician_id text (phone → technicians/{phone})
rating int 1..5, comment text
idx: (technician_id, created_at desc) + (request_id)

Dart: review.dart ✓

🎟️ promo_codes
code text unique, discount_type percentage|fixed
discount_value numeric, min_order_amount numeric
max_uses int, used_count int
valid_from, valid_until timestamptz
is_active bool
idx: (code) where is_active

Method calculateDiscount(orderAmount) in model. RPC increment_used_count(uuid) atomic.

🎧 support_tickets
user_id, user_type, subject, description
status open|in_progress|resolved|closed
priority low|medium|high|urgent
admin_reply text, updated_at timestamptz
idx: (user_id,status) + (status,priority)
🔍 search_index — full-text (tsvector)
entity_type technician|service|post
entity_id text (Firestore doc ID/phone)
title, description, governorate, specialty
search_vector tsvector GENERATED AS
  to_tsvector('simple', title||description||specialty) STORED
unique(entity_type, entity_id)
idx: GIN(search_vector) + (governorate, entity_type)

RPC search_entities(q, etype, gov, lim) ranked by ts_rank.

💳 payment_logs — audit trail
firebase_request_id, firebase_user_id (UID)
technician_id (phone), amount numeric, currency EGP
payment_method card|cash|wallet|instapay
status pending|completed|failed|refunded
stripe_payment_id, gateway_response jsonb
idx: (firebase_user_id, created_at) + (technician_id, created_at)

Reuse for Instapay or create instapay_transactions if separate flow (instapay_repository.dart exists).
